Tipos de datos en Mysql

Texto : Para almacenar texto usamos una cadena de caracteres las cadenas se colocan entre comillas simples. Podemos almacenar digitos con los que no se realizan operaciones codigos de identificacion, numeros de documentos, numeros telefonicos Varchar, char, text

Numeros : Existen variedad de tipos numericos para representar enteros, negativos, decimales, Para almacenar numeros enteros

Fechas y horas : Para guardar fechas y horas dispones de varios tipos: date, datetime, time, year, timestamp
